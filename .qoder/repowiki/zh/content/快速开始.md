## 简介

本指南旨在为新手开发者提供一份详细的KnifeManager开发环境搭建教程。KnifeManager是一个基于Vue 3和Element Plus的现代化刀具管理系统，采用Vite作为构建工具，实现了三权分立的权限管理模式，为制造业提供专业的刀具借出、库存管理和数据统计解决方案。

通过本指南，您将学习如何从零开始搭建开发环境，包括克隆项目仓库、安装必要的开发工具、配置环境变量、启动开发服务器以及构建生产版本。我们还将提供常见问题的排查方法，确保您能够顺利运行项目。

## 环境准备

在开始搭建KnifeManager开发环境之前，请确保您的系统已安装以下基础工具：

### Node.js 安装
KnifeManager项目要求Node.js版本不低于16.0.0。您可以通过以下步骤检查和安装Node.js：

1. 打开终端或命令提示符，执行以下命令检查Node.js版本：
```bash
node --version
```

2. 如果未安装或版本过低，请访问[Node.js官方网站](https://nodejs.org/)下载并安装LTS版本。

3. 验证安装是否成功：
```bash
node --version
npm --version
```

### 包管理器选择
KnifeManager支持npm、pnpm和yarn三种包管理器。您可以根据个人偏好选择其中一种：

- **npm**：Node.js自带的包管理器
- **pnpm**：更高效的包管理器，节省磁盘空间
- **yarn**：快速、可靠、安全的依赖管理

安装pnpm：
```bash
npm install -g pnpm
```

安装yarn：
```bash
npm install -g yarn
```

## 环境变量配置

KnifeManager使用`.env`文件来配置不同环境的变量。项目中包含两个主要的环境配置文件：

### 开发环境配置
`.env.development`文件用于开发环境配置：

```env
# 页面标题
VITE_APP_TITLE = 刀具柜管理系统

# 开发环境配置
VITE_APP_ENV = 'development'

# 若依管理系统/开发环境
VITE_APP_BASE_API = '/dev-api'
```

### 生产环境配置
`.env.production`文件用于生产环境配置：

```env
# 页面标题
VITE_APP_TITLE = 若依管理系统

# 生产环境配置
VITE_APP_ENV = 'production'

# 若依管理系统/生产环境
VITE_APP_BASE_API = '/prod-api'

# 是否在打包时开启压缩，支持 gzip 和 brotli
VITE_BUILD_COMPRESS = gzip
```

### 环境变量说明
- `VITE_APP_TITLE`：设置页面标题
- `VITE_APP_ENV`：指定当前环境（development/production）
- `VITE_APP_BASE_API`：设置API请求的基础路径
- `VITE_BUILD_COMPRESS`：生产环境打包时的压缩方式

## 启动开发服务器

配置完成后，您可以启动开发服务器进行本地开发。

### 启动命令
根据您使用的包管理器，执行相应的启动命令：

使用npm：
```bash
npm run dev
```

使用pnpm：
```bash
pnpm run dev
```

使用yarn：
```bash
yarn dev
```

### 服务器配置
开发服务器的配置在`vite.config.js`文件中定义：

```javascript
server: {
  port: 8081,
  host: true,
  open: true,
  proxy: {
    '/dev-api': {
      target: 'http://localhost:8080', // 后端接口
      changeOrigin: true,
      rewrite: (p) => p.replace(/^\/dev-api/, '')
    }
  }
}
```

### 访问应用
启动成功后，浏览器将自动打开，您可以在以下地址访问应用：
```
http://localhost:8081
```

如果端口8081被占用，Vite会自动尝试其他端口。

## 构建生产版本

当开发完成并准备部署时，需要构建生产版本。

### 构建命令
执行以下命令构建生产版本：

使用npm：
```bash
npm run build:prod
```

使用pnpm：
```bash
pnpm run build:prod
```

使用yarn：
```bash
yarn build:prod
```

### 构建配置
构建配置在`vite.config.js`文件中定义：

```javascript
build: {
  sourcemap: command === 'build' ? false : 'inline',
  outDir: 'dist',
  assetsDir: 'assets',
  chunkSizeWarningLimit: 2000,
  rollupOptions: {
    output: {
      chunkFileNames: 'static/js/[name]-[hash].js',
      entryFileNames: 'static/js/[name]-[hash].js',
      assetFileNames: 'static/[ext]/[name]-[hash].[ext]'
    }
  }
}
```

构建完成后，项目将在`dist`目录生成生产版本的静态文件，可直接部署到Web服务器。

## 常见问题排查

### 端口冲突
如果开发服务器启动时提示端口被占用，可以：

1. 检查8081端口是否被其他程序占用：
```bash
netstat -ano | findstr :8081
```

2. 修改`vite.config.js`中的端口号：
```javascript
server: {
  port: 8082, // 修改为其他端口
  host: true,
  open: true
}
```

### 依赖安装失败
如果`npm install`命令执行失败，可以尝试：

1. 清除npm缓存：
```bash
npm cache clean --force
```

2. 使用国内镜像源：
```bash
npm config set registry https://registry.npmmirror.com
```

3. 删除`node_modules`目录和`package-lock.json`文件后重新安装：
```bash
rm -rf node_modules package-lock.json
npm install
```

### 环境变量不生效
确保环境变量文件命名正确：
- 开发环境：`.env.development`
- 生产环境：`.env.production`

Vite会根据当前模式自动加载对应的环境变量文件。

### API请求失败
如果前端无法访问后端API，请检查：
1. 后端服务是否已启动
2. `vite.config.js`中的`target`地址是否正确
3. 代理配置是否正确

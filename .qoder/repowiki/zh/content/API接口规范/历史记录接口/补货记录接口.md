## 接口概览

补货记录模块提供了一套完整的API接口，用于管理刀具补货的全生命周期操作。该模块支持分页查询、数据导出、详情查看、统计分析、批量删除、创建和更新等核心功能，满足刀具管理系统中对补货操作的全面管理需求。

## 关键字段业务含义

### 库存变更字段

| 字段名 | 业务含义 | 数据类型 | 示例值 |
|--------|---------|---------|-------|
| oldStockNum | 操作前库存数量 | 数字 | 20 |
| newStockNum | 操作后库存数量 | 数字 | 50 |
| quantity | 补货数量 | 数字 | 30 |

这些字段用于记录补货操作前后库存数量的变化，`quantity`字段的值等于`newStockNum`减去`oldStockNum`。

### 价格变动字段

| 字段名 | 业务含义 | 数据类型 | 示例值 |
|--------|---------|---------|-------|
| oldPrice | 变动前单价 | 数字 | 120.00 |
| newPrice | 变动后单价 | 数字 | 125.50 |

这些字段用于记录刀具单价的变化情况，支持对价格调整进行追踪。

### 操作类型字段 (logType)

| 枚举值 | 中文含义 | 业务场景 |
|--------|---------|---------|
| RESTOCK | 补货 | 常规补货操作 |
| EMERGENCY_RESTOCK | 紧急补货 | 库存告警时的紧急补货 |
| NEW_PRODUCT_RESTOCK | 新品补货 | 新采购刀具入库 |
| PLANNED_RESTOCK | 计划补货 | 按计划进行的定期补货 |
| REPAIR_RESTOCK | 返修补货 | 返修后重新入库 |

## 复合查询示例

### 基于品牌的查询

通过`brandName`参数可以按品牌名称查询补货记录：

```javascript
getRestockRecordList({
  brandName: '三菱',
  startTime: '2024-12-01 00:00:00',
  endTime: '2024-12-31 23:59:59'
})
```

### 基于刀具类型的查询

通过`cutterType`参数可以按刀具类型查询补货记录：

```javascript
getRestockRecordList({
  cutterType: '车刀片',
  recordStatus: 4
})
```

### 基于时间区间的查询

通过`startTime`和`endTime`参数可以按时间区间查询补货记录：

```javascript
getRestockRecordList({
  startTime: '2024-12-27 00:00:00',
  endTime: '2024-12-27 23:59:59',
  logType: 'EMERGENCY_RESTOCK'
})
```

### 复合条件查询

支持多个条件的组合查询，例如查询特定品牌在特定时间内的紧急补货记录：

```javascript
getRestockRecordList({
  brandName: '京瓷',
  cutterType: '铣刀',
  startTime: '2024-12-01 00:00:00',
  endTime: '2024-12-31 23:59:59',
  logType: 'EMERGENCY_RESTOCK',
  size: 20,
  current: 1
})
```

## 统计接口使用方法

### 基本统计查询

`getRestockRecordStats`接口支持对补货记录进行统计分析：

```javascript
getRestockRecordStats({
  startTime: '2024-12-01 00:00:00',
  endTime: '2024-12-31 23:59:59'
})
```

### 按品牌统计

通过添加`brandName`参数可以按品牌进行统计：

```javascript
getRestockRecordStats({
  brandName: '三菱',
  startTime: '2024-12-01 00:00:00',
  endTime: '2024-12-31 23:59:59'
})
```

### 按刀具类型统计

通过添加`cutterType`参数可以按刀具类型进行统计：

```javascript
getRestockRecordStats({
  cutterType: '车刀片',
  startTime: '2024-12-01 00:00:00',
  endTime: '2024-12-31 23:59:59'
})
```

### 补货趋势分析

结合时间区间和分组参数，可以进行补货趋势分析：

```javascript
// 按月统计补货趋势
getRestockRecordStats({
  startTime: '2024-01-01 00:00:00',
  endTime: '2024-12-31 23:59:59',
  groupBy: 'month'
})

// 按日统计紧急补货趋势
getRestockRecordStats({
  startTime: '2024-12-01 00:00:00',
  endTime: '2024-12-31 23:59:59',
  logType: 'EMERGENCY_RESTOCK',
  groupBy: 'day'
})
```

统计接口返回的数据可用于生成补货趋势图表，帮助分析补货模式和预测未来需求。

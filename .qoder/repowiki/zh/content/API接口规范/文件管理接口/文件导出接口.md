## 简介
本文档详细说明了系统中文件导出功能的API设计与实现。该功能支持异步导出机制，允许用户创建导出任务、查询导出状态以及下载生成的文件。文档涵盖`fileExport.js`中的核心接口，包括导出任务创建、状态查询和文件下载等操作，并解释了后台报表生成、任务队列处理和进度轮询的设计原理。

## 异步导出机制
系统采用异步导出模式，避免长时间运行的导出操作阻塞主线程。当用户发起导出请求时，系统会创建一个后台任务，立即返回任务ID，客户端可通过该ID轮询任务状态。

```mermaid
sequenceDiagram
participant 用户界面
participant API控制器
participant 导出服务
participant 任务队列
participant 文件存储
用户界面->>API控制器 : 发起导出请求
API控制器->>导出服务 : 创建导出任务
导出服务->>任务队列 : 添加异步任务
导出服务-->>API控制器 : 返回任务ID
API控制器-->>用户界面 : 返回任务状态(处理中)
loop 轮询检查
用户界面->>API控制器 : 查询任务状态
API控制器->>导出服务 : 获取任务状态
导出服务-->>API控制器 : 返回当前状态
API控制器-->>用户界面 : 返回状态信息
end
任务队列->>导出服务 : 执行导出任务
导出服务->>文件存储 : 保存生成的文件
导出服务->>导出服务 : 更新任务状态为完成
```

## 任务管理与状态查询
导出任务具有完整的状态管理机制，包括待处理、处理中和已完成三种状态。系统通过唯一任务标识符跟踪每个导出任务，并设置了合理的过期时间策略。

```mermaid
stateDiagram-v2
[*] --> 待处理
待处理 --> 处理中 : 任务开始
处理中 --> 已完成 : 生成成功
处理中 --> 失败 : 生成错误
已完成 --> [*] : 文件过期
失败 --> [*] : 任务清理
```

## 文件下载流程
文件下载接口专门设计用于安全地传输生成的文件内容。系统采用blob响应类型确保二进制文件的完整传输，并在下载后更新下载计数等统计信息。

```mermaid
flowchart TD
A[用户请求下载] --> B{验证任务状态}
B --> |已完成| C[获取文件路径]
B --> |未完成| D[返回错误]
C --> E[读取文件流]
E --> F[设置响应头]
F --> G[传输文件内容]
G --> H[更新下载统计]
H --> I[完成下载]
```

## 典型使用场景
以库存统计报表导出为例，展示完整的调用序列。用户首先触发导出操作，系统创建任务并返回标识符，随后通过轮询机制检查任务状态，最后在任务完成后下载文件。

```mermaid
sequenceDiagram
participant 前端 as 前端界面
participant API as 文件导出API
participant 服务 as 导出服务
前端->>API : POST /fileManagement/fileExport/export
API->>服务 : 创建导出任务
服务-->>API : 返回任务ID
API-->>前端 : 返回任务信息
loop 每5秒轮询
前端->>API : GET /fileManagement/fileExport/{id}
API->>服务 : 查询任务状态
服务-->>API : 返回状态
API-->>前端 : 显示进度
end
前端->>API : GET /fileManagement/fileExport/download/{id}
API->>服务 : 获取文件流
服务-->>API : 返回文件
API-->>前端 : 下载文件
```

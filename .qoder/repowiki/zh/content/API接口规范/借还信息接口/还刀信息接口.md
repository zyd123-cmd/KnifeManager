## 引言
还刀信息API接口是刀具管理系统中的核心功能模块，负责处理刀具归还相关的所有数据操作。该接口为还刀管理页面提供数据支持，实现了还刀记录的查询、新增、修改、删除和导出等功能。系统采用前后端分离架构，前端通过Vue 3框架与后端RESTful API进行交互，确保了数据的实时性和准确性。

## 核心接口功能

还刀信息API接口提供了完整的CRUD（创建、读取、更新、删除）操作，满足还刀管理的各种业务需求。

### 还刀记录查询
`listReturnInfo(query)` 函数用于查询还刀信息列表，支持多种条件筛选。该接口通过GET请求访问 `/borrowReturnInfo/returnInfo/list` 端点，接收查询参数对象，实现灵活的数据检索功能。

### 条件筛选机制
接口支持基于员工ID、刀具编号、时间区间等多种条件的复合筛选。查询参数通过URL参数形式传递，系统会根据提供的筛选条件返回匹配的还刀记录。

### 分页机制
接口内置分页功能，通过分页参数控制数据返回量，避免一次性加载过多数据导致性能问题。默认每页显示20条记录，支持10、20、50、100等不同分页大小选择。

### 数据操作接口
除了查询功能，接口还提供了完整的数据操作能力：
- `getReturnInfo(id)`：获取单条还刀信息详情
- `addReturnInfo(data)`：新增还刀信息
- `updateReturnInfo(data)`：修改还刀信息
- `delReturnInfo(id)`：删除还刀信息
- `exportReturnInfo(query)`：导出还刀信息

## 关键数据字段说明

还刀信息接口返回的数据包含多个关键字段，每个字段都有特定的业务含义。

### 归还状态
`borrowStatus` 字段表示还刀状态，采用数值编码：
- 0：修磨
- 1：报废
- 2：换线
- 3：错领

该字段在前端通过颜色标签可视化展示，便于用户快速识别不同状态。

### 操作人信息
`borrowUserName` 字段记录执行还刀操作的员工姓名，`lendUserName` 字段记录原始借刀人姓名。这两个字段帮助追踪刀具的流转过程和责任归属。

### 归还时间
`borrowTime` 字段记录还刀操作的具体时间，采用标准时间格式（YYYY-MM-DD HH:mm:ss）。该时间戳对于分析刀具使用周期和生成统计报表至关重要。

### 刀具信息
包含 `cutterCode`（刀具型号）、`cutterType`（刀具类型）、`brandName`（品牌名称）和 `specification`（规格）等字段，完整描述了归还刀具的特征。

### 记录状态
`recordStatus` 字段表示记录的当前状态：
- 0：取刀
- 1：还刀
- 2：收刀
- 3：暂存

该字段反映了刀具在管理系统中的生命周期阶段。

## 接口安全性

系统采用多层次的安全机制保护还刀信息接口。

### JWT认证
所有API请求都需要JWT（JSON Web Token）认证。前端在请求头中添加Authorization字段，格式为"Bearer + Token"。

```javascript
// request.js中的拦截器
if (getToken() && !isToken) {
  config.headers['Authorization'] = 'Bearer ' + getToken()
}
```

### Token管理
系统使用Cookies存储JWT Token，通过专门的auth工具进行管理：
- `getToken()`：从Cookies获取Token
- `setToken(token)`：设置Token到Cookies
- `removeToken()`：从Cookies移除Token

### 权限控制
系统实现了基于角色的访问控制（RBAC），不同角色拥有不同的操作权限：
- 管理员：完整操作权限
- 审计员：只读查看权限
- 操作员：有限操作权限

### 会话过期处理
当Token过期（返回401状态码）时，系统会弹出重新登录提示，并自动跳转到登录页面。

## 常见问题排查

以下是还刀信息接口常见的问题及排查方法。

### 认证失败
**现象**：返回401状态码
**原因**：Token过期或缺失
**解决方案**：
1. 检查浏览器Cookies中是否存在Admin-Token
2. 尝试重新登录获取新Token
3. 检查请求头是否正确包含Authorization字段

### 数据不显示
**现象**：表格为空或显示"暂无数据"
**原因**：
1. 查询条件过于严格
2. 分页参数错误
3. 后端服务异常
**解决方案**：
1. 重置查询条件
2. 检查网络连接
3. 查看浏览器控制台是否有错误信息

### 导出失败
**现象**：导出功能无响应或提示失败
**原因**：
1. 未选择要导出的记录
2. 网络超时
3. 文件保存权限问题
**解决方案**：
1. 确保至少选择一条记录
2. 检查网络连接稳定性
3. 确认浏览器有文件保存权限

### 接口超时
**现象**：请求长时间无响应
**原因**：后端处理时间过长或网络延迟
**解决方案**：
1. 优化查询条件，减少返回数据量
2. 检查服务器性能
3. 确认网络连接质量
